AzaharPlus Discord対応 カスタム配布版
作成日: 2026-10-13 / Windows x64

これはAzaharPlusの非公式カスタム版です。
上流: https://github.com/AzaharPlus/AzaharPlus
上流ベース: cf9068844820f819a6eabbeeeb6a70d546e3e85a
ローカルベース: 4e2c35e05929ef20f364767489a5b93b204eb3cf

使い方
1. ZIPをフォルダーにすべて展開します。
2. azahar.exeを起動します。exeの隣にあるDLLやpluginsフォルダーも必要です。
3. 設定画面の「全般」→「ネットワーク」で、Discordの状態表示を切り替えます。
4. OKで保存します。設定画面を開き直しても、選択した状態を維持します。
5. Discordに表示する場合は、Discordデスクトップ版を起動し、活動の共有を有効にします。

既存環境から移行するとき
通常は既存の %APPDATA%\AzaharPlus を使います。
既存フォルダーを上書きする前に、アプリを終了し、セーブと設定をバックアップしてください。
まず別フォルダーで起動して確認する方法を推奨します。
このZIPに個人の設定、セーブ、ROM、アカウント情報は含まれていません。

この版の変更
・Discord Rich Presenceを組み込んでビルドしました。
・Discord設定のチェック状態を読み戻せない条件名の不整合を修正しました。
・プレイ中は、プロフィールカード上部とメンバー一覧にゲーム名を表示します。
・ゲーム未起動時やゲーム名を取得できない場合はAzaharPlusと表示します。
・Discordが付ける「プレイ中」の文言と重複しないよう、ゲーム名だけを送ります。
・対応ゲームでは、プロフィールカード内の画像をゲームのアイコン画像にします。
・ボイスチャンネル一覧の小さいアプリアイコンは、Discordに登録された花のままです。
・ゲームIDから公開画像を選び、Discordがインターネット経由で画像を取得します。
・画像は3DS-dBの公開画像を使用します。ROM内の画像や個人のファイルは送信しません。
・未登録のゲーム、ゲームIDを取得できない場合、ゲーム未起動時は花アイコンを使用します。
・画像提供元やネット接続の状態によって、画像を表示できない場合があります。
・以前のUDS PullPacket修正と診断ログを維持しています。
・以前のSDLコントローラー初期化時のロック順序修正を含みます。
・別用途のBadge Lab試験変更は含めていません。

検証結果
validation.jsonを参照してください。
録画機能は以前のカスタム版と同じく無効です。
ゲーム全般の動作、2台間の通信・レース完走は今回の検証範囲に含みません。
